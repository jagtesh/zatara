ZATARA / BROWSER

A window onto the web.

This page is running in the real terminal-browser. Its process belongs to your persistent desktop. It is intentionally static for reproducible performance measurements.

Independent

Move this window without moving the editor. Each application owns its state, while Zatara owns placement and focus.

Persistent

Detach the desktop, reconnect, and continue where you left off. A network connection is not a session lifetime.

Mouse first

Drag, resize, minimize and restore. Use the taskbar to bring a window forward.

Measured

No animation, video, or external assets on this page. This makes idle CPU and scroll measurements reproducible.
